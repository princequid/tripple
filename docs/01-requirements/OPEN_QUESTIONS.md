## 1. How this register works

- Every question has an **owner**, a **needed-by task** (from [MASTER_PROJECT_WORKFLOW.md](../MASTER_PROJECT_WORKFLOW.md)), a **linked decision** where one exists and a **default assumption**.
- If a question is still open when its needed-by task starts, the work proceeds on the **default assumption**, and the lead records it in the DECISION_LOG. Changing the answer later is a change request (workflow rule 1.1a-17). This follows rule 1.1a-7: no answer is assumed silently.
- **Blocks R1** = "Yes" only when no safe default exists, or when the default would cause rework of R1 deliverables already in progress. Those questions have a **needed-by date**. The P01-07 target is at most 3 such questions.
- Agents never decide these questions; answers come from the user, or from the lead for technical items, and are recorded by the lead.
- Status values: Open · Answered · Superseded.
